# Evidence and provenance

RECOVERED means extracted original data with an exact source locator. COMMUNITY-SOURCED means a source-backed archive/page/screenshot claim. INFERRED is a derived hypothesis; INFERRED-FIXTURE is an explicit replica policy; UNKNOWN remains missing or unresolved. Native runtime verification is a separate status, not implied by extraction.

Every generated claim includes source_id, repository path, SHA-256, record/line/key locator and label. Statistical observations additionally retain raw text, displayed units, level/rank/gear/buff context and whether they qualify as base-stat evidence.

Never turn missing evidence into zero, interpret historical archive values as final-version base balance, blend different levels/equipment states, or use the current replica as proof of original stats. Conflicting source values remain separate observations.

Original source bytes are immutable. Normalization/export tools are deterministic; edited historical documents have a preserved original-byte copy and a transformation record. The original complete AGENTS.md is preserved privately; its historical claims are not all current.

# Sources

client-tables/ contains recovered reference JSON, LevelDB table exports and raw JET chunks. native/ contains decompiler/disassembly/string evidence, indexed by system. community/raw/ contains local archived forum/wiki/VSFan material with original retrieval/provenance files. observations/ contains retained screenshots, runtime probes and regression sessions.

Raw community material and observations are ignored until reviewed for personal data and publication rights. Their presence supports offline research and reproducible work; it does not grant permission to publish the originals.

Large preservation artifacts and private captures live in local/. Use the migration ledger rather than guessing from a filename whether an artifact is redundant.

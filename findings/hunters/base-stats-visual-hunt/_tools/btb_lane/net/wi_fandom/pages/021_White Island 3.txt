{{Season_Template|release_date = Nov 07, 2012|episodes_number = Unknow|playable_characters = Unknow|image1 = Game WI3 Title.jpg}}White Island 3 marks the end of the previous White Island storyline. [[Seo Hyun]] is the main character but it is unknown if she is the playable character. Also, it marks the return of [[Ji Hoon]] and [[Jae]].

This game brought a huge performance boost and mechanics improvement, the 3D scenes used in the current game also began here. This game marked the [[White Script]] as a very powerful and lightweight engine.

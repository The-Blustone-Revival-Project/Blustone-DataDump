- **Set:** Man of Justice
  - Weapon: **Blue-Back Justice** — To Harley it is a symbol of justice because it has a never changing, deep blue color and a straight, sharp bill that never bends.
  - Armor: **Masked Hero Suit** — Even though he gets mistaken for a perv or it makes one suspect that it stops blood circulation, he still wears it bravely.
  - Accessory: **Hero's Mark** — Without this mark, the costume looks too empty. This mark is essential in order to differentiate whether he is a superhero or a supervillain.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `046|TITLE`, `046|SUMMARY`, `046|WEAPON`, `046|WEAPON_DESC`, `046|ARMOR`, `046|ARMOR_DESC`, `046|ACCESSORY`, `046|ACCE_DESC`, `046|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

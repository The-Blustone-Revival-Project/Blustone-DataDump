- **Set:** Prayer
  - Weapon: **Huge Mace** — Despite its outrageous weight, Junia handles it as if it were a feather.
  - Armor: **Ascetic’s Combat Uniform** — A unique combat uniform that looks too uncomfortable to be solely for battle.
  - Accessory: **Black Veil** — Nobody has ever seen Junia’s hair unveiled to this day.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `076|TITLE`, `076|SUMMARY`, `076|WEAPON`, `076|WEAPON_DESC`, `076|ARMOR`, `076|ARMOR_DESC`, `076|ACCESSORY`, `076|ACCE_DESC`, `076|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

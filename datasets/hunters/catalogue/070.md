- **Set:** Electrotherapist
  - Weapon: **Stun Gun** — Alia says it’s not a weapon… But it’s a frightful weapon for those who are receiving attacks.
  - Armor: **Insulating Dress** — The appearance is nothing special, but it prevents electrocution as the inside is filled with insulating material.
  - Accessory: **Battery Pack** — Due to the fact that electricity is generated semi-permanently, it looks like it has been made with ancient Metron technology.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `070|TITLE`, `070|SUMMARY`, `070|WEAPON`, `070|WEAPON_DESC`, `070|ARMOR`, `070|ARMOR_DESC`, `070|ACCESSORY`, `070|ACCE_DESC`, `070|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

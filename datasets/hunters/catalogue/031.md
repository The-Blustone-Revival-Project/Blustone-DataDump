    `namu.wiki/w/블루스톤/헌터`]: 3 Rage for Offense/Defense, 4 Rage for

    `value`, `value_up` and `duration`. Skill levels 1..5 are real:
    `skill_1_level`..`skill_5_level` are native keys (see
    `analysis/recovered-data/native-key-vocabulary/deck-and-arity.tsv`).
- **Set:** Thunder Arrow
  - Weapon: **Thunder Arrow** — A sacred arrow that has protected the tribe from generation to generation. It is an ancient relic that nests the power of thunder.
  - Armor: **Punk Rabbit Jacket** — A limited-edition punk jacket that Diana just bought by queueing up in front of the store since dawn.
  - Accessory: **Ribbon Hair Tie** — A very strong ribbon hair tie that can handle Diana's extremely thick hair.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `031|TITLE`, `031|SUMMARY`, `031|WEAPON`, `031|WEAPON_DESC`, `031|ARMOR`, `031|ARMOR_DESC`, `031|ACCESSORY`, `031|ACCE_DESC`, `031|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

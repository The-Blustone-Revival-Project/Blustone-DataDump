  - Weapon: **Wolf Knuckles** — Knuckles that are nailed with solid, wolf teeth. The power of these knuckles is great and with them, you can take on enemy attacks head-on.
  - Armor: **Batwoman Dress** — A dress that cosplays Batwoman. A hot item among cosplayers.
  - Accessory: **Bat Wings Cape** — Paired with real big bat wings to recreate the look. But the down-side is that it smells like a bat too...
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `034_1|TITLE`, `034_1|SUMMARY`, `034_1|WEAPON`, `034_1|WEAPON_DESC`, `034_1|ARMOR`, `034_1|ARMOR_DESC`, `034_1|ACCESSORY`, `034_1|ACCE_DESC`, `034_1|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually

    Weapon -> Attack Power, Armor -> Defensive Power,

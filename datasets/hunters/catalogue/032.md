  - Game-wide rule for cross-checking [COMMUNITY-SOURCED
    `namu.wiki/w/블루스톤/헌터`]: 3 Rage for Offense/Defense, 4 Rage for

    `value`, `value_up` and `duration`. Skill levels 1..5 are real:
    `skill_1_level`..`skill_5_level` are native keys (see
    `analysis/recovered-data/native-key-vocabulary/deck-and-arity.tsv`).
- **Set:** Wandering Fighter
  - Weapon: **Frost Gauntlet** — A weapon that injects coolant, freezing everything in the area instantly. This has been on Scar ever since he woke up.
  - Armor: **Ripped Jeans** — The difference between vintage and old is confidence! But you can't help getting cold from the cold wind breaking in through the rips.
  - Accessory: **Ancient Necklace** — A necklace that Scar has been wearing since he woke up. There are ancient characters on it, but no one can read it.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `032|TITLE`, `032|SUMMARY`, `032|WEAPON`, `032|WEAPON_DESC`, `032|ARMOR`, `032|ARMOR_DESC`, `032|ACCESSORY`, `032|ACCE_DESC`, `032|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

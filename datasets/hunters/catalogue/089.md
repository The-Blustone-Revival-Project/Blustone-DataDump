- **Set:** Post Office Supervisor
  - Weapon: **Pandahawk** — Handle Pandahawk with care. He's Clara's best friend but is notorious for the bad temper.
  - Armor: **Arm Protector** — It has great defensive power as it blocks Pandahawk's claw, which is famous for its sharpness.
  - Accessory: **Coffee Rabbit Tribe's Bandana** — It has to be made twice as elaborate as a normal bandana not to cover Coffee Rabbit Tribe's ear.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `089|TITLE`, `089|SUMMARY`, `089|WEAPON`, `089|WEAPON_DESC`, `089|ARMOR`, `089|ARMOR_DESC`, `089|ACCESSORY`, `089|ACCE_DESC`, `089|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

- **Set:** Genius Climatologist
  - Weapon: **Snowball Slingshot** — A heavy snowball and a modified slingshot. No one knows what's inside the snowball.
  - Armor: **Pilot Jacket** — A jacket made by a high-end kids brand. This is the only clothing that Dino took with him when he ran away from home.
  - Accessory: **Anemometer Backpack** — A backpack that has an anemometer attached to it. A climatologist needs to be able to check the climate any time, any place.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `054|TITLE`, `054|SUMMARY`, `054|WEAPON`, `054|WEAPON_DESC`, `054|ARMOR`, `054|ARMOR_DESC`, `054|ACCESSORY`, `054|ACCE_DESC`, `054|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

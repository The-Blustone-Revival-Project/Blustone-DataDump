  - Game-wide rule for cross-checking [COMMUNITY-SOURCED

    `skill_1_level`..`skill_5_level` are native keys (see

- **Set:** Captain
  - Weapon: **Crying Sword** — A sword that shoots light and lightning when used with force. No one else but Captain can handle this sword.
  - Armor: **Red Combat Coat** — A red coat that Captain has been wearing since he woke up. It is very light and warm, so many people want it.
  - Accessory: **Unknown Epaulet** — It is a surprise that Captain can't remember a single thing about this emblem. You can't help but feel Captain's ingenuousness.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `009|TITLE`, `009|SUMMARY`, `009|WEAPON`, `009|WEAPON_DESC`, `009|ARMOR`, `009|ARMOR_DESC`, `009|ACCESSORY`, `009|ACCE_DESC`, `009|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

- **Set:** Nature's Gift
  - Weapon: **Bear's Claws** — A weapon created by nature. Sometimes Bear gets her nails done when going to the nail shop with Akasha.
  - Armor: **Bear's Hide** — The fur has been tangled and hardened so it functions like an armor. The function may be great but it's unhygienic.
  - Accessory: **Bear's Feet** — Bear's big, roundish feet are somehow cute. Captain ended up in the hospital for 3 weeks because he played around with Bear's squishy feet.
  - All of the above are [RECOVERED] `CHAR_STR_RO` keys `036|TITLE`, `036|SUMMARY`, `036|WEAPON`, `036|WEAPON_DESC`, `036|ARMOR`, `036|ARMOR_DESC`, `036|ACCESSORY`, `036|ACCE_DESC`, `036|VICTORY`.
    NOTE: these are *named pieces*, not set bonuses. The game has **no**
    gear-set bonus system — each hunter owns exactly one weapon, one armor
    and one accessory, upgraded individually
    [COMMUNITY-SOURCED `Blustone Guide FAQ.md` L301-L346].
  - Gear -> stat mapping [COMMUNITY-SOURCED FAQ L303-L305]:
    Weapon -> Attack Power, Armor -> Defensive Power,
    Accessory -> Life Points.

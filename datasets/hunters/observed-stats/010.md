### White values as a conditional base-stat anchor

The screen uses the same white-stat / green-equipment-delta layout as Beckhen's
FAQ image 17. On that identified card, white Strength `24068` plus green `+6291`
reconciles exactly to the separate card-page Strength `30359`; the HP/ATK/DEF
white values also align with the recorded item/jewel deltas. This cross-screen
check supports reading the orphan's white values as its gear-removed stat line:
**HP 2866 / ATK 1522 / DEF 1103**, with Strength 23847 and Attack Speed 8.00.
Its level, rarity/rank, awakening, and catalog identity are not visible, so this
is an anonymous base-state anchor for rebalance estimates, not a catalog row.
Confidence: high for the printed digits, medium for transferring the calibrated
UI semantics to this second card.

**Identity: [UNKNOWN].** It is demonstrably not Beckhen — under a consistent
reading the values differ from `051`'s on every axis, and this build's gear is much
weaker, so it cannot be a gear variant of the same card. It is also not Vincent
`010` (whose geared Strength is 33038, not 23847). It is recorded here as an
orphan rather than attached to a card id. [OCR-UNCERTAIN on identity, OCR-CONFIDENT
on the numbers]

### The Attack Speed observation
Base Attacking Speed reads **8.00 on two different cards** (`051` and this
unidentified one). [DERIVED, n=2] Base Attack Speed is plausibly a **game-wide
constant of 8.00**, which would make it a safe global default rather than a
per-card figure. Too few observations to assert; recorded because it is cheap for
the server to adopt provisionally and trivial to falsify.
